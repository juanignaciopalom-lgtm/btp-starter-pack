EL PROBLEMA

¿Cuántas horas
perdiste configurando SAP BTP?

La configuración inicial de un entorno SAP BTP Cloud Foundry implica instalar herramientas, autenticarse con SSO, crear servicios en el orden correcto y lidiar con bugs conocidos que SAP no documenta claramente.

  • 📚Documentación SAP dispersa en múltiples portales y versiones
  • 🔗Error grant_type: missing por AppRouter bindeado al plan incorrecto
  • ⏱️Passcode SSO de CF expira en 60 segundos — sin aviso previo
  • 🔧npm ci rompe el build de MBT en ciertos entornos
  • 🔄Dependencias circulares en mta.yaml que detienen el deploy

QUÉ INCLUYE

Todo lo que necesitás
para arrancar con SAP BTP

Una sola herramienta cubre el wizard de configuración, la generación del proyecto y el deploy. Más dos manuales detallados para que entiendas cada paso.

🧙
Wizard de 6 pasos
Interfaz web paso a paso que guía desde la verificación de dependencias hasta el deploy completo. Estado persistente entre sesiones, con botón de reset por paso.
🔧
4 Auto-repairs antes del deploy
Detecta y corrige automáticamente los 4 bugs más comunes del mta.yaml: plan incorrecto del AppRouter, npm-ci, xsuaa-deployer y dependencias circulares.
⚡
CLI completo
Todos los comandos disponibles también por terminal: doctor, init, login, setup, generate-project, deploy. Integrable en pipelines CI/CD.
🏗️
Generador de proyectos
Genera proyectos CAP + SAPUI5 + AppRouter listos para evolucionar. Incluye mta.yaml, xs-security.json, estructura de carpetas y scripts de build.
🛡️
Seguridad by design
Sin almacenamiento de credenciales. Autenticación 100% via OIDC browser. Validación de inputs contra command injection (CWE-78, CWE-88). Logs con sanitización de tokens.
📖
Documentación completa
Dos manuales interactivos: uno para usar la herramienta y otro para hacer el proceso manual, ambos descargables en PDF. Basados en documentación oficial SAP.

INSTALACIÓN

En marcha
en 4 comandos

Cloná el repositorio, instalá las dependencias, compilá y abrí el wizard. Todo lo demás lo hace la herramienta.

  • 🟢 Node.js18+ LTS
  • ☁️ CF CLIv8.x (no v7)
  • 🔑 SAP BTP CLI2.x
  • 📦 MBT1.2+

¿Faltan herramientas? El comando doctor --fix te guía para instalar cada una.

# 1. Clonar el repositorio git clone https://github.com/juanignaciopalom-lgtm/rma.git cd rma/btp-starter-pack # 2. Instalar dependencias del backend npm install # 3. Compilar frontend npm run build:ui # 4. Compilar TypeScript → JavaScript npm run build # 5. Iniciar el wizard en tu máquina local npm run start:ui # → abre automáticamente el browser en http://localhost:3001
💡 El wizard verifica y guía la instalación de las herramientas SAP. Podés empezar con solo Node.js y Git.
